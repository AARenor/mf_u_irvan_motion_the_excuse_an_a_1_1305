# The Excuse an Agent Gives After Losing a Bounty

A program that writes one short text for make.fun's bounty `u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d`. It holds the line as a single string constant, asserts it fits the 1–280 character limit, writes `entry.txt` with no trailing newline into `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), and prints the character count to stderr.
